Recensioni Google

Mostra in home un carosello con la media, il numero e le recensioni da 4 e 5 stelle della scheda Google, dalla più recente alla più vecchia, e nella pagina Valutazione la media e il numero. Places API (New) fornisce solo 5 recensioni scelte da Google: se sulla stessa chiave abiliti anche la Places API classica, il sito aggiunge le 5 più recenti. I dati si aggiornano da soli ogni 12 ore; se Google non risponde restano i link alla scheda. Serve una chiave della Places API (New) creata in Google Cloud: in “Limitazioni delle API” lascia solo Places API (New); in “Limitazioni delle applicazioni” scegli “Indirizzi IP” con l’IP del server oppure “Nessuna” (la restrizione “Siti web” è pensata per il browser, ma il sito invia comunque il proprio indirizzo).

Altri codici di tracciamento

Per strumenti che non hanno un campo dedicato (es. Hotjar, LinkedIn Insight, TikTok Pixel, Pinterest): incolla il codice che ti dà il servizio, scegli la categoria di consenso e dove inserirlo. Il codice parte solo dopo che il visitatore ha accettato quella categoria; «Necessari» parte sempre, quindi usalo solo per codici che non tracciano. Il nome compare nelle preferenze cookie e nella pagina Cookie. Gli attributi onclick/onload e gli eval sono bloccati dalla sicurezza del sito: i codici standard dei servizi funzionano.

Invio diretto a Google e Bing

Quando pubblichi o modifichi una pagina o un articolo del blog (anche quelli che arrivano da Frase o ContentAI), il sito mette l’indirizzo in coda e lo invia da solo a Google (Indexing API) e a Bing (Webmaster API), fino al limite giornaliero per motore. Gli articoli tolti dal sito vengono segnalati a Google come rimossi. Alla prima attivazione entrano in coda tutte le pagine e gli articoli: partono qualche giorno alla volta, prima gli articoli più recenti. IndexNow, nella scheda Servizi indicizzazione, resta attivo come prima.

Come collegare Google, passo per passo
  1. Apri Google Cloud Console con l’account Google che gestisce il sito e crea un progetto (o scegline uno esistente).
  2. Vai in API e servizi → Libreria, cerca Web Search Indexing API e premi Abilita.
  3. Vai in IAM e amministrazione → Account di servizio → Crea account di servizio: dagli un nome (es. «indexing-sito»), non servono ruoli, premi Fine.
  4. Apri l’account di servizio appena creato → scheda Chiavi → Aggiungi chiave → Crea nuova chiave → JSON: si scarica un file .json. Tienilo riservato.
  5. Copia l’email dell’account di servizio (finisce con .iam.gserviceaccount.com).
  6. Apri Search Console, scegli la proprietà che contiene gli indirizzi del sito (tipo Dominio valutazionediamanti.it, oppure prefisso URL https://www.valutazionediamanti.it/ con il www) → Impostazioni → Utenti e autorizzazioni → Aggiungi utente: incolla l’email e scegli l’autorizzazione Proprietario. Con «Completo» o «Limitato» Google rifiuta gli invii con l’errore 403 «Failed to verify the URL ownership». Se l’email è già nell’elenco con un altro ruolo, apri i tre puntini accanto e cambiala in Proprietario; per farlo il tuo account deve essere Proprietario verificato della proprietà.
  7. Qui sotto carica il file JSON, spunta «Invia a Google», premi Salva e poi Prova il collegamento.

Google dichiara l’Indexing API pensata soprattutto per offerte di lavoro ed eventi in diretta: le notifiche delle altre pagine vengono accettate, ma è Google a decidere se e quando rileggerle. La quota standard è di 200 invii al giorno.

Come collegare Bing, passo per passo
  1. Apri Bing Webmaster Tools: il sito deve essere già verificato (meta tag msvalidate.01 qui sopra, oppure importato da Search Console), con lo stesso indirizzo dell’URL pubblico del sito.
  2. Premi l’ingranaggio Impostazioni in alto a destra → Accesso API → Chiave API → Genera chiave API e copiala.
  3. Incollala qui sotto, spunta «Invia a Bing», premi Salva e poi Prova il collegamento: il sito mostra la quota giornaliera che Bing concede al sito.
